# skinsight 护肤品成分解读

把护肤品成分表（中文或英文 INCI 都可以）贴进来：

- **成分解读**：粘贴成分表，或者上传成分表照片自动识别（本地 OCR，图片不保存）。逐个显示成分的标准中文名、作用，以及香精/香料致敏原、高位酒精、甲醛释放体防腐剂、致痘评分较高等提示，并列出需注意的人群（敏感肌、孕期哺乳期、医美术后等）。
- **叠用检查**：填 2–4 个准备一起用的产品，检查维A + 酸、维A + 过氧化苯甲酰、多个去角质产品叠用等冲突，并给出建议。

成分知识库收录 377 个常见成分，中文名以《已使用化妆品原料目录（2021年版）》为准。源码：https://github.com/me-Kaia/skinsight

**免责声明**：本工具仅供学习和信息参考，不构成医疗或皮肤科诊疗建议。致痘评分来自早期动物实验，仅供参考；产品的实际表现取决于浓度和整体配方。皮肤出现持续不适请咨询医生。
